# TechPass — приложение техника (Android)

Это Android-оболочка для демонстрационного приложения техника. Она показывает тестовые профили и генерирует обновляемый QR-код. Данные вымышленные; это не производственная система допуска.

## Как получить APK через GitHub Actions
1. Создайте пустой репозиторий GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** и запустите workflow **Build TechPass APK** (или дождитесь автоматического запуска после push).
3. Откройте завершённый запуск workflow, найдите **Artifacts** и скачайте `techpass-technician-debug-apk`.
4. Распакуйте архив и установите `app-debug.apk` на Android. При необходимости разрешите установку приложений из выбранного источника.

## Ограничения демо
- QR-библиотека загружается с CDN, поэтому для генерации QR нужен интернет.
- Токен и проверка не защищены серверной криптографией; это только макет интерфейса.
- Не используйте настоящие ИИН, персональные данные или реальные сведения о допусках.
- Для реального запуска необходимы серверная проверка короткоживущего токена, авторизация, отзыв доступа и аудит.
