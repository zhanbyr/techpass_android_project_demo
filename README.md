# TechPass — техник, реестр и отдельный сканер

APK открывает меню с двумя независимыми разделами: прежнее приложение техника и новый нативный реестр подрядчиков. Веб-сканер проверяющего остаётся отдельной страницей и не объединяется с приложением техника.

1. **Debug APK:** сборки находятся в [GitHub Actions](https://github.com/zhanbyr/techpass_android_project_demo/actions/workflows/build-apk.yml). После успешной сборки скачайте артефакт `techpass-technician-debug-apk`.
2. **Веб-реестр компаний и специалистов:** [открыть на GitHub Pages](https://zhanbyr.github.io/techpass_android_project_demo/registry/). Включает профили, направления, назначения и их историю, QR, импорт Excel, демонстрационные согласования и журнал действий.
3. **Веб-сканер проверяющего:** [открыть отдельный сканер](https://zhanbyr.github.io/techpass_android_project_demo/qr/).
4. **Старая демо-база персонажей:** [Excel-файл](demo-database.xlsx). Она остаётся отдельным примером для экрана техника и веб-сканера.

Нативный реестр APK также поддерживает локальную SQLite-базу, ручное добавление и импорт `.xlsx`. Данные веба хранятся в `localStorage`; изменения между браузером и APK не синхронизируются, поскольку серверной части нет. Демо-роли и согласования показывают процесс, но не являются механизмом безопасности. QR содержит только EMP-ID. Все данные и номера вымышленные; старые профили Харухи, Кёна, Микуру и Ицуки не смешиваются с записями подрядчиков.
